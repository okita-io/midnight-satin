# Midnight Satin - Design Reference

This project is a premium romance reading app called **Midnight Satin**. All implementation must follow the design screens and PRD in `reference/`.

## Design Direction

- **Theme:** Tactile Noir Luxury — deepest onyx backgrounds, metallic gold accents
- **Device:** Mobile-first (iOS/Android)
- **Colors:** Primary gold (#D4AF37), void black (#050505), surface (#121212), burgundy accent (#800020)
- **Typography:** Playfair Display (titles), Cinzel (headings), Literata (body), Marcellus (UI)
- **Stack:** Next.js with Tailwind CSS

When implementing screens, always reference the corresponding HTML design file in `reference/` for exact layout, styling, and component structure.
